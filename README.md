# Bulldog ETH Bank

A secure Ethereum banking web application built with:

- Node.js
- Express.js
- MySQL
- Sequelize
- EJS
- MetaMask Integration
- Web3.js / Ethers.js

## Features

- User authentication
- Role-based access control
- Ethereum wallet integration
- Deposit & withdrawal tracking
- Transaction logging
- Admin dashboard
- Secure session management
